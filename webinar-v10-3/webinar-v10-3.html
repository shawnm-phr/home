People Intelligence, Wherever You Are

Wednesday, 19 August 2026 | 12:30 PM IST

What We'll Cover

In this webinar, we'll walk you through the latest features and updates in PeoplesHR v10.3. This includes the latest enhancements to Lexi AI, now smarter and available on mobile, plus the new Lexi Super Agent update that lets one agent handle HR, payroll, and time requests in a single conversation. We'll also cover Work From Anywhere, the new Payroll Control Centre for catching errors before payroll runs, faster payslip access, and the latest compliance updates for Sri Lanka, the Philippines, and Indonesia.

  • Lexi AI Insights: now smarter, and available on mobile
  • Lexi Super Agent: one agent for HR, payroll, and time requests
  • Work From Anywhere: flexible arrangements with location control
  • Payroll Control Centre: catch and fix payroll errors before they run
  • Faster payslip access, plus the latest compliance updates for Sri Lanka, the Philippines, and Indonesia
